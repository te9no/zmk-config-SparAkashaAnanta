# Ananta ZMK 0.4 — 右TB / 左ENC 検証版 rc.1

対象は **右親機＝PMW3610トラックボール、左子機＝エンコーダ、IQSなし** です。

## ダウンロード

- 右親機: `SAA_R_MODULE_TB.uf2`
- 左子機: `SAA_L_MODULE_ENC.uf2`

左右を取り違えないでください。今回の修正は主に右側です。
既存のZMK環境向けで、RMKへの移行ファームやsettings resetではありません。

## 変更内容

- 右TBをDYA Studioのマウス入力処理へ接続。
- 通常時のAML初期設定をMouseレイヤー（3）に設定。
- Fn（1）/ Scr（4）でボール移動をスクロールへ変換。
- Motion無効または全バイト0xffのセンサー読み取りを捨てるガードを追加。

DYAに保存済みの設定は初期値より優先されます。AMLが動かなければ
マウス入力処理の有効状態と対象レイヤーを確認してください。
既存キーマップの全消去やペアリング削除は不要です。

## 検証状況・制限

- just.shで左ENC・右TBのビルド成功。生成DTSとガード組み込みを確認。
- ガード/入力経路の3テスト、58キー・6レイヤーのレイアウト検証に合格。
- **実機未検証です。暴走が解消したとはまだ断定できません。**
- **左右の文字入力の詰まり、長押し中の引っ掛かりは未解決・調査中です。**
- 左の書き込み時ポップアップの原因も未確認です。

まず現在のDYA設定をエクスポートし、既存ファームを手元に残してください。
問題があれば前回の公開版 `zmk-0.4-20261013` に戻してください。
UF2のSHA256とビルド証跡JSONを同梱します。
