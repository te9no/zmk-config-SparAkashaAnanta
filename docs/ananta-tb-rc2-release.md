# Ananta ZMK 0.4 — All modules rc.2

## 変更内容

- 右PMW3610の読み取りをバースト方式へ変更し、通信回数を削減。
- DYA Studioのデバイス情報・クラッシュ履歴・キースイッチ診断・スタック使用量を追加。
- 通常ログをINFOへ抑制し、移動ごとのDEBUGログ出力を停止。
- LTを短押し優先、長押し判定350ms、連続タップ200msに調整。
- rc.1以降のスケーリング計算のオーバーフロー対策とPMW動作設定修正を含む。

## 実機確認

右TB・左ENC（IQSなし）で、無線接続時にShiftなどを押しながら
トラボを操作する際の引っかかりがなくなったことを利用者が確認。
センサー初期化と左右接続も確認済みです。
全構成の長期動作やセンサー画像のバースト取得まで検証したものではありません。

## 書き込み

右TB・左ENCの場合は `SAA_R_MODULE_TB.uf2` と `SAA_L_MODULE_ENC.uf2`。
その他は左右・モジュール・IQS有無に対応するUF2を選んでください。
左右の診断機能を揃えるため、左右とも更新してください。
既存設定・ペアリングの消去は不要です。更新前にDYA設定をエクスポートしてください。
`settings_reset` は通常の更新には使用しません。

全モジュールのビルドと実機検証は別です。本リリースはプレリリースです。
